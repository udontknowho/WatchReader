# WatchDownloader 1.6.1.1

版本码：42。包名：`com.watchdl`。最低 Android 11。

## 修复

- 收藏身份隔离，搜索收藏后刷新标记，目录、正文、下载页增加收藏入口。
- 在线阅读独立保存目录，无收藏、无下载也可从阅读记录恢复。
- 同地址不同书独立保存快照、历史、章节和偏移，不借用其他书的下载任务。
- 恢复目标书源，修正正文阅读记录入口，防止删除历史后生命周期写回。
- 缓存使用完整摘要目录，迁移旧缓存时核对身份。
- 更新检查支持三段和四段版本号。

## 书源与更新

- 内置17条书源保持不变。本版未重新在线抽检。
- 搜索暂时仅返回番茄的现象已由用户确认恢复，未将其归因为书源丢失。
- 云源仓库仍为私有，应用默认地址不能匿名更新；包内书源不受影响。
- **1.6.1旧版的更新解析器只接受三段版本，会拒绝本版四段标签。请从本发布页直接下载APK升级。**

## 验证

- 核心与全部界面编译通过，38组JVM回归分别通过。
- 正式签名、4字节对齐、ZIP CRC、包内版本和书源一致性校验通过。
- 未安装、未执行设备界面测试。“只能收藏搜索第一本”的实际根因尚未复现。
