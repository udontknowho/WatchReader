# WatchDownloader v1.6.0（code 40）

四栏导航、独立收藏、阅读翻页修复与书源精简的整合版本。

## 产物

- 包名：`com.watchdl`。最低 Android 11，目标 Android 14。
- APK：`WatchDownloader-1.6.0-release.apk`，1783416 字节。
- SHA256：`b473ec0f76350f7ead73a51c4469c306a789ebf461250aa994d46a6966fd22e5`。
- 正式证书 SHA256：`0635de25e9c423c272b3607c62ed9426405796ba2c67fe0a4626717e557276d0`。
- 正式证书与既有 1.5.1 相同，版本代码从 39 升至 40。

## 改动

- 四栏导航为书架、收藏、发现、我的。收藏与下载状态独立。
- 统一配色、返回入口、下载进度入口及次级功能页面。
- 修复阅读分页边界、末页与跨章翻页衔接。
- 内置源库精简为 16 条，不再采用旧版 38 条统计口径。
- 云端源清单升至第 8 版，文件与本版内置源库相同。
- 榜单配置升至第 4 版，起点使用官网九榜，未确认分页不开放。

## 验证与限制

- `bash build.sh test` 运行退出码为 0，共 33 组回归及 1 组语法诊断。
- 语法诊断支持 16/22 项，不代表全部现代 JavaScript 或 Legado 宿主兼容。
- 尚不支持箭头默认参数、对象解构默认值、调用展开、数组展开、class、async。
- 核心与完整界面编译、ZIP CRC、4 字节对齐、正式签名和 dex 校验通过。
- 翻页回归 43 项，导入预览 11 项，次级功能 16 项。
- 源库验收使用实际引擎检查搜索、非截断目录及前中后三章正文。
- 每章至少 300 个汉字，且正文不重复、不含明显错误页。
- 在线抽检只覆盖样本与检查时段，不保证全部作品、章节或后续访问。
- 分类与周期筛选仅有 4 次在线抽检证据。女频入口未验证可用性。
- 本次未安装、未进行真机验证。仓库首页图片来自历史版本。

## 使用与复现

- 安装命令：`adb install -r WatchDownloader-1.6.0-release.apk`。
- 校验命令：`sha256sum WatchDownloader-1.6.0-release.apk`。
- 项目目录回归命令：`MIN_AVAIL_MB=1536 bash build.sh test`。
- 项目目录构建命令：`APP_VERSION=1.6.0 APP_VERSION_CODE=40 bash build.sh`。
- 构建会清空 `build/`，正式发布副本保存在 `releases/v1.6.0/`。

## 回滚

- 源码回滚可对本版提交执行 `git revert <本版提交哈希>`。
- 云源回滚应恢复上一版内容，再发布递增清单版本，避免客户端拒绝旧版本。
- Android 不保证直接降级安装。卸载会删除应用私有数据，回滚前应导出。
