# WatchDownloader 1.6.1

版本码：41。包名：`com.watchdl`。最低 Android 11。

## 修复

- 目录分页共享脚本库，使用逐页地址解析，明确报告截断。
- 收藏兼容旧存档，保留多来源候选，同书匹配同时检查书名和作者。
- 换源先验证目录，再迁移进度。失败重试保留原书上下文。
- 番茄榜单直接读取包内 UTF-16 字符表。
- 表冠使用单个逐帧任务，快速输入继续累加滚动目标。
- 关于页接入正式仓库，点击检查 GitHub 正式版本。
- 起点男频全站月票榜接入官网真实分页。匿名 Cookie 和令牌仅保存在内存，月份读取官网元数据，失败不推进页码。
- 内置 17 条书源，新增搬山人小说网。云源清单同步至第 9 版。

## 验证

- 36 组 JVM 回归通过，Android 界面编译通过。
- Python 验收调度器 3 项离线测试通过。
- Kotlin 起点测试 51 项通过，含真实首批和第二批各 20 本，书籍编号交集为 0。
- 原 16 条源中 15 条通过在线抽检，飞卢一条目录截断，状态未定并保留。新增源通过两轮独立抽检。
- 正式签名校验、4 字节对齐、ZIP CRC、dex SHA1 及包内源库一致性校验通过。
- 未安装到设备，未执行真机界面测试。其他起点榜单仍只展示首批。正文分页兼容边界沿用原版。
- 云源仓库当前为私有仓库，匿名访问返回 404。已认证核验第 9 版和源库字节一致，但应用默认地址不能匿名更新。包内 17 条源不受影响，未更改仓库可见性。

## 安装与回滚

安装：`adb install -r WatchDownloader-1.6.1-release.apk`。
更新前可自行备份应用数据。Android 通常拒绝降版本覆盖安装，旧包不是数据回滚工具。
源码回滚可基于上一版标签 `v1.6.0` 建分支，或恢复本地回滚包中的原文件。
