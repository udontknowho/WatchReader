顶栏新方案 + 底栏指示点尺寸

底栏三点按你的意见改小了。顶栏再给六个方案，最下面一台是活的，能拖。

先说上一版为什么看着大：我按 6 dp 画的，且整机放大了两倍。手表上常见的指示点是 3 dp 上下， 选中态做成短条。这一版按 3 / 2.5 / 2 dp 三档重画，你挑一个。

一 · 底栏指示点（三档，单选）

点间距都是 5 dp。选中态是同一高度的短条，长度是点的 3 倍。

3 dp · 推荐
2.5 dp · 更小
2 dp · 下限
2 dp 在这块屏上大约是 4 个像素的直径，圆角基本看不出来，看着像小方点。 再加手指遮挡，非选中点会很难判断在哪一栏。3 dp 是我建议的底。

四 · 六个方案的取舍

方案占屏搜索入口代码量主要风险
T5 只留 ⋮ 2525 dp进菜单，多一次点小无
T6 标题居中 2626 dp左侧图标小与右滑手势冲突
T7 悬浮图标 00 dp右上浮标小压住首排封面
T8 折叠标题 44→2424–44 dp图钉在右侧最大滚动插值的手感
T9 分段页签 2424 dp无位置，需另放中与 B4 重复，二选一
T10 透明叠加 00 dp右上浮标中滚动时文字重叠
我的建议是 T5。它比 T2 再省 7 dp，且把搜索收进菜单后，顶栏只剩标题与一枚按钮， 在 189 dp 宽里不再拥挤。要更激进就 T7，但首排封面得留 20 dp 顶距。
