## 三、P0-11 · 阅读器正文几乎看不见

- 现象：阅读器正文为极浅的紫白色，白底与米底上都几乎不可读。
- 实测像素（截图取样，正文区）：

| 背景选项 | 背景色 | 文字色 | 对比度 |
|---|---|---|---|
| 白 | `#FFFFFF` | `#E6E0E9` | **1.30:1** |
| 暖 | `#FFF8E6` | `#E6E0E9` | **1.22:1** |

- 定位：`MainActivity.kt:141` `private var readerBackground = Color.WHITE`，而 `:696` 正文色是 `Md3.onSurface`（`0xFFE6E0E9`，深色主题配色）。背景两个选项（白 / 暖）都是浅色，文字色没有跟着换。
- 影响：阅读页是产品唯一的目的地。当前状态等于「下完了，看不了」。
- 与第 1 轮对照：上一版阅读器背景是深色，`t24-reader.png` 里文字清晰。本轮把背景显式设为白色，是回归。
- 修法二选一：
  1. 背景默认改 `Md3.surface`（`#141218`），浅色文字保持不变；
  2. 保留浅色背景，把文字色改成 `0xFF1C1B1F`，并在设置里按背景切换文字色。

```kotlin
// 最省事的做法：让背景跟着主题走
private var readerBackground = Md3.surface
```

## 六、未验证项

## 七、复现要点

```sh
~/vd/vd.sh start 378 496 320
ID=$(cat ~/tmp/vd.id)
/system/bin/su -c "unset LD_LIBRARY_PATH LD_PRELOAD; /system/bin/am start --display $ID -n com.watchdl/.MainActivity"

# 进阅读器：首页点书 → 目录点第 1 章 → 截图 → 点右下「下一章」
# 重命名：首页 ⋮ → 重命名 → vd.sh clip 斗破苍穹 → vd.sh paste → 保存
```

**环境坑（本轮新增）**：
1. OCR 输出的坐标是文字包围盒的**左上角**，不是中心。点击时 y 要加 8–12 px；底栏按钮更明显，y=450 落空、y=462 命中。上一行只差 12 px 就会误判成「按钮失效」。
2. 重命名/删除/阅读设置都是系统 `AlertDialog`，不套应用主题；在小屏上内容会超出可视区，需要滑动才能看到后面的选项。
3. 虚拟屏上不会弹软键盘，所以重命名对话框不会被输入法遮挡——真机上需要复核。
