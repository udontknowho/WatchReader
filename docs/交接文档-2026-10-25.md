## 验证方式

编译前先读 `build.sh` 里的两道闸：

- 闸一：`flock` 保证同一时间只跑一个构建
- 闸二：`MemAvailable < 1536 MB` 拒绝开编

```bash
grep MemAvailable /proc/meminfo       # 低于 1.5 GB 先清后台
cd ~/WatchReader && bash build.sh test # 全量自检
bash build.sh                          # 出 APK
```

`JAVA_OPTS` 已被 `build.sh` 封顶为 `-Xmx384m` + 串行 GC。要放开就 `JAVA_OPTS=-Xmx512m bash build.sh …`。

## 环境约束

本机内存 15.1 GB 常年已用 14 GB。编译峰值约 700 MB，越线会触发系统杀进程，**连 Termux 自己和 pi 会话一起被杀**（10-24 晚实测）。所以：

- 不要并发构建
- 不要边编译边开大应用
- 长任务要发 `termux-notification`，否则看不出卡在哪
