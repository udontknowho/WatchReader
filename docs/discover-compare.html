怎么选

方案空态首屏出书改动量适合
A 能力位消失是小只想把 bug 修掉，界面别动
B 补数据消失是最小先看起点女频数据能不能用
C 列表化消失否中想要一个干净、一次能翻完的榜单目录
D 两级消失否中站点要留按钮，性别退成组标题

我的建议：C 打底，顺手把 B 的起点女频榜补进配置。A 如果只想立刻止血，就单独改，不必等重写。C 与 D 的差别只在顶部那一行按钮要不要留。
