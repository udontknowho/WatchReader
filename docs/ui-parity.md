# UI 对照表：legado → 手表版

参考方：`~/ref/legado-novel` @ `2ed09db`（3.26.21）。
目标方：`~/WatchDownloader`（`com.watchdl`，纯 Android View，无 Compose）。
屏级结构明细见 `legado-screens.md`，本文只写映射与取舍。

## 结论：能"一比一"到什么程度

**结构可以，像素不行。**

legado 是手机布局，逐屏都假设了 ≥360 dp 宽度与长按多选。目标屏 189 × 248 dp，
不到的宽度装不下原结构。所以本文的"一比一"指三件事：

1. **信息层级一比一**：同一屏看到哪几层信息、按什么顺序，与 legado 一致。
2. **分组与标签一比一**：分组标题、菜单分组的划分和中文原文一致。
3. **字号与节奏一比一**：字号阶、行高、圆角、间距取自 legado 数值，再按手表压档。

不追求：图标像素级还原、动画曲线、材质混合（legado 用 Glass 系列，需 Compose）。

### 裁剪的判据（2026-11-01 修正）

以前拿“一屏显示不下”当裁剪理由，这是错的。**纵向列表可滚动，装得下任意多项。**
只有下面三种情况才算真装不下：

1. **同一行里摆 N 个元素**：189 dp 一行放 6 个图标，每个不足 28 dp。
2. **需要横向滑动的分页**：页签行、HorizontalPager，没空间再放内容。
3. **希望一眼看完的控件**：颜色选择器、两级多选树，滚动也无法使用。

所以“我的”12 项、“书详情”全部字段都照搬，靠上下滚动。

## 设备基准（已核实）

| 项 | 值 |
|---|---|
| 目标机 | OPPO Watch 3 Pro，1.91" LTPO AMOLED |
| 分辨率 | 378 × 496 px，326 ppi |
| dp | 378×496 @320dpi = **189 × 248 dp** |
| 虚拟屏 | `~/vd/vd.sh start 378 496 320`（与真机一致） |

`Md3.configure()` 按 `screenWidthDp` 分档，189 dp 命中 `else -> 1f`，即基准档。

## 逐屏映射

现有 `Screen` 共 11 个（`core/Screen.kt`），legado 侧 11 屏。缺口用「**缺**」标出。

### 1. 书架 → `Home` + `Shelf`

| 项 | legado | 手表版 |
|---|---|---|
| 顶栏 | 「书架」+ 分组页签 | `Home` 顶栏「小说下载器」，无页签 |
| 主体 | 分组 HorizontalPager + 网格/列表两档 | `Home` 是入口页（搜索框 + 发现榜单 + 书架），`Shelf` 是封面墙 |
| 底部 | 导航条：书架 / 发现 / 我的 | 无底部导航 |
| 菜单 | 11 项（远程书籍 … 日志） | 无 |

**差距**：没有分组、没有两档布局。
**动作**：`Shelf` 增封面墙（3 列、5:7 封面 + 书名一行），与现有列表档并存，
切换入口放顶栏 ⋮。两档都做，默认封面墙。
分组页签不搬，理由：页签行是横向滑动，189 dp 首行就没空间了。

### 2. 发现 → `Discover`（已有）

| 项 | legado | 手表版 |
|---|---|---|
| 顶栏 | 「发现」+ 分组副标题 + 搜索切换 | 站点/性别切换 + 榜单选择 |
| 主体 | 书源卡 → 展开出种类栅格（一行最多 6 份） | 榜单选择器 → 条目列表 |
| 菜单 | 长按书源卡：置顶 / 编辑 / 搜索 / 登录 / 刷新 / 删除 | 无 |

**判断**：模型不同。legado 的发现是"书源驱动"，本项目的发现是"站点榜单驱动"（番茄/起点）。
不追平。只对齐视觉：书源卡圆角 12 dp、展开箭头 18 dp。

### 3. 我的 → **缺**（本轮新建）

legado 分两组：

- 「规则」：书源管理 / 替换净化 / TXT 目录规则 / 字典规则 / 标签规则
- 「其它」：设置 / 书签 / 阅读记录 / 缓存管理 / 文件管理 / 关于 / 退出

**动作**：新建 `Screen.My`，12 项全要，两组分组标题照搬，靠滚动容纳。
每项标题取自 `values-zh-rCN/strings.xml` 原文。

### 4. 书详情 → **缺**（本轮新建）

legado：封面 5:7 + 书名 + 作者 + 书源 + 标签 + 4 张操作卡 + 在读/最新 + 简介 + 相关书籍 + FAB「阅读」。

**动作**：新建 `Screen.Detail`，纵向滚动排下来，字段全留：
封面（手表上给 60 dp 宽）+ 书名 + 作者 + 书源名 + 分类标签 + 在读章名 + 最新章名
+ 「共 N 章」+ 简介（可展开）+ 底部 FAB「阅读」。
4 联操作卡改 **2×2**，四格仍是放入书架 / 查看目录 / 换源 / 阅读记录。
裁掉：半透明封面大背景、相关书籍横排（后者是横向列表，与本屏主路径无关）。

### 6. 阅读页 → `Reader`（已有）

| 项 | legado | 手表版现状 | 差距 |

### 7. 阅读设置 → `Settings` 的一部分

legado 是四个页签（全局 / 菜单 / 信息 / 更多），条目走分组，每项 = 标题 + 描述 + 当前值 + 控件。

**动作**：不新建屏，`Settings` 首节「外观」+「阅读显示」已覆盖核心三项（字号/行距/背景）。
补 legado 的排版纪律：标题 `titleMedium`、描述 `bodySmall` 70% 透明、当前值 `labelMedium` + primary。
裁掉：颜色选择器、自定义背景、屏幕方向/刘海组。

## 共性数值对照（legado → Md3）

| legado | 值 | Md3 现状 | 结论 |
|---|---|---|---|
| 横向内边距 | 16 dp（M3）/ 12 dp（miuix） | `PAD = 8` | 手表压到 8，不动 |
| 组间垂直留白 | 8 dp | `GAP = 6` | 接近，不动 |
| 卡片圆角 | 16 dp（分组）/ 8 dp（书架列表）/ 4 dp（网格项） | `R_CARD = 12` / `R_ITEM = 10` | 改为 16 / 8，网格项新增 4 |
| 按钮圆角 | — | `R_ITEM = 10` | 保持 |
| 分组标题 | `labelLarge` + primary，左缩进 16 | `sectionLabel` | 见下 |
| 设置项标题 | `titleMedium`（16sp） | `FS_MD = 12` | 手表档不追平 |
| 设置项描述 | `bodySmall`（12sp）+ 70% 透明 | `FS_SM = 11` + `onSurfaceVariant` | 一致 |
| 设置项当前值 | `labelMedium`（13sp）+ primary | `FS_SM` + `onSurfaceVariant` | **改为 primary** |
| 顶栏动作图标 | 24 dp | 未定 | 新增常量 |
| 菜单项前导图标 | 18 dp，间距 12 dp | 无前导图标 | 不搬（189 dp 放不下） |
| 封面比例 | 5:7 | 无封面 | 书架用 5:7 |
| 列表底部留白 | 120 dp | 无 | 手表用 8 dp |
| 字号阶 | 32/24/20/18/17/16/14/13/12/11 | 17/14/13/12/11 | **已对齐，P0 完成** |
| 行高 | paragraph 1.2 em | `readerSpacing` 默认值有 | 一致 |

**只有三处要改**：卡片圆角（12→16/8，新增 4）、设置项当前值改 primary、补两个图标尺寸常量。

## 明确不做

| 项 | 理由 |
|---|---|
| 分组页签与横滑切组 | 189 dp 顶栏装不下；分组用下拉替代 |
| 长按多选与拖拽重排 | 手表长按易误触，且无批量操作场景 |
| 底部导航条（书架/发现/我的） | 248 dp 高，去掉 48 dp 导航条只留 5 行正文 |
| Glass 系列材质与共享元素转场 | 依赖 Compose，手搓流水线上不存在 |
| 侧滑抽屉、FAB 展开菜单 | 手表无边缘手势语义 |
| 阅读页 6 个顶栏按钮 | 降为 3×2 图标格，一次点开 |
| 表情/字体/颜色选择器 | 189 dp 无法排布 |

## 已拍板

1. **「我的」屏：建**，12 项全要，分组标题照搬。
2. **书详情屏：建**，字段全留，4 联操作卡改 2×2。
3. **书架封面墙：要**，与列表档并存，默认封面墙。

原则：能滚就滚，不拿“一屏显示”当裁剪理由。
只有同一行摆 N 个元素、或横向分页的情况才真装不下。

## 落地顺序

先做共性数值（3 处，改动小、全局生效），再按屏改造。
`bash build.sh test` 的失败项必须始终是 6。
