一、还没做的功能

优先级功能现状
缺口最大听书（TTS / 朗读） 全无。源码里没有任何 tts 相关代码，阅读页也没有朗读条。legado 的朗读是一整套：选音、语速、定时、跳章。
缺口最大本地书籍导入 只能从书源下。txt / epub 放进来读不了，这是「手表阅读器」最说不过去的一条。
有依赖EPUB 导出 只有 TXT。Downloader.exportText 已支持分章与标题清洗，加 EPUB 是套一层 zip + XHTML。
有依赖备份与恢复 没有 WebDav。设置页已明写不做，书架「远程书籍」是占位提示。要做得先定同步到哪里。
已定方案缓存页导出入口 导出能力已有（目录页 ⋮、阅读页 ⋮），缓存页没有入口。方案见第二节，已按 A + C 落地。
已定方案批量导出 一次只导一本。已加「导出全部」，范围为当前筛选出的这一批。
要改模型书籍分组 / 标签、收藏书架 缓存页的「书架书籍 / 未在书架」是按“下没下完”临时分的。真分组要加收藏动作与分组字段。
要动取数市场内搜索、批量导入对话框 市场只能翻页找。legado 的网络导入有「批量导入」对话框与搜索。
要动取数按书源分组的发现 我们的榜是 RankConfig 硬表，没有 exploreUrl，做不出 legado 那种「每个书源自己的发现页」。
主动砍阅读页查词 / 翻译、章节图片、段评 没做，理由写在对应屏注释里。
不做创建堆转储、检查更新、版本日志列表 Debug.dumpHwHeap 只对 debuggable 包有效；没有发布渠道；日志只有一个 dev.log。

按价值排：TTS 与 本地书籍导入 是两条真正的功能缺口，其余是打磨。点表格里任意一行可以勾选，选中的会出现在屏底。

二、缓存管理加导出键

前提：导出能力已经有了——MainActivity.exportTxt(info) 带目录顺序重排、原子写、写「文档/」重名自动加 (2)。缓存页缺的只是入口。

不能随手加：书卡末行现在是「状态汇总 + 播放/停止 + 删除」两颗 32dp 图标。再塞第三颗，汇总只剩约 61dp，四段文字必被截成「下载中 0 ·…」。

下面三张卡可以点，可多选，选完底部点「复制回执」。不选也行，已按 A + C 落地。

A

展开书卡后加一行通栏按钮「导出 TXT · 已下 N 章」

章窗口上方一行，只在展开时占 40dp。

已落地。展开本身就是“要对这本动手”的信号，默认不多占一行。没下过章的书这一行换成灰字「还没下到内容」；没下全时回执补一句「共 N 章，未下的不导」。

B

书卡末行加第三颗图标

常驻可见，但要把状态汇总挪到独立一行，多占约 26dp 高。

189dp 的屏上，一屏少一行书卡。没做。

C

屏底加「导出全部 · N 本」

与「全部开始 / 全部停止」并排，串行导出，导出中再点变「取消导出」。

已落地。范围是当前筛选出的这一批。导完汇总「已导出 X 本，失败 Y 本，跳过 Z 本（已存在）」。
