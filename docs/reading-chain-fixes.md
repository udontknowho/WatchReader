# 收藏与阅读记录链路修复

## 范围
- 修复收藏身份冲突、收藏标记刷新，以及目录、正文、下载页的收藏入口。
- 在线阅读独立保存目录快照，无收藏、无下载也可从阅读记录恢复。
- 阅读身份采用原地址和规范化书名作者摘要。网络仍使用原地址。
- 同地址不同书分别保存快照、历史和进度，不借用另一书的下载任务。
- 旧记录或旧进度存在身份歧义时不猜测归属。
- 正文阅读记录菜单进入记录页，离开正文解除会话，防止删除后写回。
- 缓存使用完整摘要目录键，迁移旧目录时核对快照身份。
- 移出收藏保留历史、进度和缓存。
