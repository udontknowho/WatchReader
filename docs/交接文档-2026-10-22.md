## 本轮已完成

### 下载服务

- 修复同一本书重复启动时误停前台服务。
- 修复切换书籍时旧任务清理新任务的问题。
- 避免主线程等待下载线程造成卡顿。
- 修复取消状态被旧快照覆盖的问题。
- 修复首次快照创建前取消的竞争。
- 修复初始化或解析异常不能正常收尾的问题。
- 第三方书源不再无条件初始化番茄设备。

### 作业存储

- `JobStore` 改为按实际作业文件共享跨实例锁。
- `job.json` 与 `chapters.jsonl` 使用同一把作业锁。
- 保留原子快照写入和缺失文件容错。
- 增加跨实例并发写入回归测试。

### 规则和导入

- 修复省略 `</body>` 时 HTML 后代节点被丢弃的问题。
- 保留合法的内部链接，避免吞掉外部节点。
- 书源头脚本依赖网络接口时，不再静默导入空请求头。
- `ajax`、`get`、`post` 网络头脚本会明确判为不支持。

### 目录超时

- 目录请求建立统一的单调时钟预算。
- 初始目录、跳转目录和分页共用剩余预算。
- HTTP 请求会接收目录剩余超时。
- 预算耗尽后保留已有章节，不继续发新请求。

2. 检查 APK 文件和源码状态。
3. 优先做真机安装前的静态检查。
4. 用户确认后再安装 APK。
5. 首次真机回归覆盖：启动下载、取消、切换书籍、锁屏、恢复下载、第三方书源。
6. 真机验证后再决定是否初始化本地 Git。

## Git 建议

建议使用本地 Git，不要求上传远程仓库。初始化前应先检查目录中的密钥、APK、测试数据和个人配置，并写入 `.gitignore`。不要把以下内容提交到仓库：

- `debug.keystore`
- `release.keystore`
- `keystore-info.txt`
- 构建目录中的 APK 和签名文件
- 真实书源数据和个人测试数据
- 含账号、令牌或请求头的配置文件
