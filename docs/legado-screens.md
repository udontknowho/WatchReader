# legado 屏级结构清单（供手表版对齐）

源：`~/ref/legado-novel` @ 2ed09db（3.26.21，全 Compose）。目标屏 189×248 dp。
标签一律抄 `values-zh-rCN/strings.xml` 中文原文。文件按屏归类，未列的小组件不展开。

## 书架（app/src/main/java/io/legado/app/ui/main/bookshelf/BookshelfScreen.kt）
- 顶栏：`GlassMediumFlexibleTopAppBar`，标题「书架」（加载中显示「加载中…」）+ subtitle；右侧动作依次 搜索 → 编辑模式下换成 全选/反选/下载/移入分组/标记为私密/删除选中；编辑模式左侧图标变关闭（取消选择）；顶栏 bottomContent 放分组页签 + 「分组管理」下拉按钮
- 主体：`HorizontalPager` 按分组分页，每页 `FastScrollLazyVerticalGrid`（列表/网格两种 layoutMode）。网格项 = 封面 5:7 + 书名最多 2 行（可居中、可叠在封面底部）；列表项 = 封面（默认宽 84dp）+ 书名 + 作者（紧凑模式「作者 · 未读N」）+ 「在读章节名」+ 标签横滑行 + 未读角标 TextCard（新章带 Update 图标）+ 可选简介若干行；分组文件夹模式额外画 N 张预览封面 + 「N 本」
- 底部：无底部栏；主框架底部是 `AppNavigationBar`：书架 / 发现 / 我的
- 菜单与弹层：更多菜单 = 远程书籍 / 添加本地 / 更新目录 / 布局设置 / 分组管理 / 添加网址 / 选择模式 / 书架管理 / 导出书单 / 导入书单 / 日志。分组下拉 = 各分组名（右侧 √），搜索态额外一组标题「全部 / 隐藏」。确认框「是否确认删除?」「是否确认开始缓存？」
- 手机专属交互：横滑切分组、下拉刷新（按分组 `enableRefresh`）、长按书籍进详情、编辑模式下点按多选、长按拖动重排、快速滚动条、封面共享元素转场
- 手表上必须裁掉的：分组页签行 + 快速滚动条 + 编辑模式工具条。理由：189dp 顶栏一行只容得下标题加 2 个图标；页签需横向滚动的分组数无上限

## 发现（app/src/main/java/io/legado/app/ui/main/explore/ExploreScreen.kt）
- 顶栏：`ListScaffold`，标题「发现」+ 副标题当前分组（空则「全部」）；搜索切换；下拉菜单列出分组（「全部」+ 各分组名）
- 主体：`FastScrollLazyColumn` 两层。上层 = 书源卡（`GlassCard` 圆角 12dp），卡内只有书源名 + 右侧展开箭头（展开时转 90° 或换成 18dp loading）；展开后每行放「发现」种类项，一行按权重最多 6 份，含文本输入类与按钮类；顶部浮动当前书源名胶囊（点击滚回该源）
- 底部：无
- 菜单与弹层：长按书源卡弹「更多菜单」= 置顶 / 编辑 / 搜索 / 登录 / 刷新 / 删除（红），首行有 `PillHeaderDivider` 显示书源名；删除确认「是否确认删除?」；空态「当前没有发现源！」
- 手机专属交互：长按弹菜单、六列权重的种类栅格、浮动吸顶胶囊
- 手表上必须裁掉的：书源卡内的种类栅格 + 浮动胶囊。理由：6 权重一行在 189dp 下每格不足 28dp，输入类控件必然溢出

## 我的（app/src/main/java/io/legado/app/ui/main/my/MyScreen.kt）
- 顶栏：标题「我的」，无动作图标
- 主体：`verticalScroll` 单列，两个 `SplicedColumnGroup`：
  - 「规则」：书源管理（副标题「新建 • 导入 • 编辑或管理书源」）/ 替换净化 / TXT 目录规则 / 字典规则 / 标签规则
  - 「其它」：设置 / 书签 / 阅读记录 / 缓存管理 / 文件管理 / 关于 / 退出
- 底部：无（沿用主框架底部导航）
- 菜单与弹层：无，全部直接跳转
- 手机专属交互：无
- 手表上必须裁掉的：12 项全保留不现实。248dp 减顶栏只剩约 3.5 行，建议只留 设置 / 书签 / 阅读记录 / 关于，其余收进「设置 → 高级」

## 书详情（app/src/main/java/io/legado/app/ui/book/info/BookInfoScreen.kt）
- 顶栏：透明 `MediumFlexibleTopAppBar`，左返回；右侧 编辑（已在书架才显示）/ 分享 / 更多操作；私密未解锁时只留返回
- 主体：`LazyColumn` 叠在半透明封面背景（`BookInfoBackdrop`）上。头部 = 封面（5:7，点击换封面，长按预览）+ 书名（最多 2 行，长按弹「搜索 / 展开」）+ 「作者：」行 + 书源名 + 高亮标签行 + 分类标签横滑 + 分组名 + 备注；其后一行 4 张等宽操作卡：放入书架（长按=分组选择） / 查看目录 / 换源 / 阅读记录；再往下 = 「在读 · 章节名」「最新 · 章节名」「共 N 章 | 已读 M 章」+ 简介（可展开、可点图）+ 相关书籍横排
- 底部：FAB「阅读」（`ExtendedFloatingActionButton`，primaryContainer）
- 菜单与弹层：更多操作 = 自定义按钮 / 编辑 / 刷新 / 阅读记录 / 重新同步远程书籍 / 上传 WebDav / 登录 / 设置源变量 / 设置书籍变量 / 拷贝书籍 URL / 拷贝目录 URL / 置顶 / 允许更新 / 拆分超长章节 / 删除提醒 / 清理缓存 / 日志 / 标记为私密；封面换源弹层：封面换源 / 编辑 / 刷新；另有「分组选择 / 新建分组 / 编辑备注」
- 手机专属交互：下拉刷新目录、整页封面模糊背景、封面共享元素转场、简介内图片点击放大
- 手表上必须裁掉的：背景大图 + 4 联操作卡 + 相关书籍横排。理由：248dp 高，光封面加书名就占满一屏；4 张卡在 189dp 下每张仅 42dp 宽

## 目录（app/src/main/java/io/legado/app/ui/book/toc/TocScreen.kt）
- 顶栏：`DynamicTopAppBar`，标题书名、副标题章节名/进度；左返回；可切搜索（占位「搜索章节…」）；选择模式下显示已选数量并换成关闭

- 底部：FAB 展开菜单 4 项 = 定位至当前阅读 / 移至顶部 / 移至底部 / 一键缓存；多选时贴底工具条 = 反选 / 选择后续 / 添加书签 + 主按钮「下载已选（N）」
- 菜单与弹层：目录页下拉 = 使用替换规则 / 显示字数 / 反转目录 / 更新目录 ─ 替换净化 / 新建替换 ─（本地书）「本地书籍选项」：本地书籍目录规则 / 拆分超长章节。书签页下拉 = 导出书签为 JSON / 导出书签为 Markdown。卷管理按钮下拉 = 展开所有卷 / 折叠所有卷 + 标题「快速跳转」+ 各卷名。空态「暂无书签」「暂无划线笔记」
- 手机专属交互：三页横滑、FAB 展开菜单、粘顶卷标题、长按多选、下拉翻到底部加载
- 手表上必须裁掉的：书签/笔记两页、FAB 四项菜单、章条右侧状态图标行。理由：189dp 一行放「章名+tag+图标」必然折行；FAB 菜单展开会盖住半个屏

## 搜索（app/src/main/java/io/legado/app/ui/book/search/SearchScreen.kt）
- 顶栏：左返回；右侧两个开关按钮 = 精准搜索（命中/未命中两套图标）、筛选（打开选择书源分组弹层）；顶栏下方 `SearchBar`（占位「搜索书名、作者」，右侧清除）
- 主体：未提交时是建议面板（搜索历史 + 书架书目，历史可单条删或「清除所有」）；提交后结果列表两种布局 —— 列表布局 or 来源分组布局。结果项 = 封面 72dp（5:7）+ 书名（右侧「N」同源份数角标）+ 作者 • 最新: xxx + 简介 2 行 + 标签横滑；左上角书架状态角标（已在书架 ✓ / 疑似重复 ⇄）；被质量检测排除的封面加模糊 + 遮罩「内容质量检测已排除」；底部「部分书源未返回，结果可能不完整。」「上拉或点击按钮加载更多」
- 底部：FAB 停止 / 开始（搜索中=停止，否则加载更多）
- 菜单与弹层：筛选页 = 选择书源分组：分组 / 书源 / 全部书源 / 书源管理 / 确认；布局模式 = 来源分组 / 列表布局；搜索类型 = 全部 / 小说 / 音频；内容质量检测 = 开始检测 / 指定检测章节 / 主角名或关键词 / 跳过章节头部字数 / 章节数量 → 内容清洗 → 多关键词匹配 → 自动排除；确认框「是否确认清除所有搜索历史记录」「%s分组搜索结果为空，是否关闭精准搜索？」「…是否切换到全部分组？」
- 手机专属交互：长按封面预览大图、输入即联想、下拉/到底加载更多
- 手表上必须裁掉的：筛选弹层的「分组 / 书源」两级多选树、来源分组布局、简介与标签行。理由：两级树在 189dp 宽下每层都需要独立滚动，收益远低于成本

## 全文搜索（app/src/main/java/io/legado/app/ui/book/searchContent/SearchContentScreen.kt）
- 顶栏：标题「搜索内容」（有结果时「共 N 条结果」）+ 左返回；右侧两个开关 = 替换开启/替换关闭、正则开启/正则关闭；顶栏下方 `SearchBar`
- 主体：空态是搜索历史列表（每项可删，可切「搜索当前书」范围）+ 清除；有结果时卡片列表，卡片 = 命中标题（关键词高亮）+ 分隔线 + 上下文正文（关键词底色）+ 右上角标签「当前章节」/「xx.x%」

- 手表上必须裁掉的：上下文正文块（卡片退化成「章节名 + 百分比」一行）。理由：卡片内三段文字在 189dp 下每段只剩 1 行，等于没有

## 换源（app/src/main/java/io/legado/app/ui/widget/components/changeSource/ChangeSourceSheet.kt、book/changesource/）
- 顶栏：不是独立屏，是 `AppModalBottomSheet`；标题「换源」/「单章换源」；startAction = 更多菜单 + 设置，endAction = 暂停/刷新 + 筛选

## 共性
- 横向内边距：`adaptiveContentPadding` 在 M3 引擎取 16dp、miuix 引擎取 12dp；书架网格例外（M3 4dp + 传入值，miuix 6dp + 传入值）；顶栏附加区内边距同此值（`adaptiveHorizontalPadding`）
- 垂直节奏：组内条目不额外留白、组与组之间上下各 8dp；下拉菜单项内边距 水平 20dp / 垂直 12dp
- 底部留白：列表 `contentPadding.bottom` 统一 120dp（给底部栏/FAB 让位）；书架在有系统导航栏时同为 120dp，否则 8dp；书详情 88dp + 系统栏
- 卡片圆角：`SplicedColumnGroup` 默认 16dp（可配置关闭或覆盖）；书架列表卡 8dp、网格项 4dp；书签聚合卡 16dp；`GlassCard` 默认取 `MiuixCardDefaults.CornerRadius`（未核数值），发现书源卡显式 12dp；角标/标签 `TextCard` 4dp
- 分组标题：`AdaptiveTitle` = `labelLarge` 字号 + primary 色，左缩进 16dp、下间距 8dp；下拉菜单内的分组标题用 `PillHeaderDivider` / `PillDivider`
- 设置项排版：标题 `titleMedium`；描述 `bodySmall`、onSurface 70% 透明；当前值 `labelMedium` + primary；右侧展开箭头 `KeyboardArrowDown` 带 180° 旋转动画；分隔线仅在 `enableItemDivider` 时出现
- 图标尺寸：顶栏动作按钮 24dp；下拉菜单项前导图标 18dp（图标与文字间距 12dp）；封面上的角标图标 12dp；章条 VIP 锁 14dp；发现卡展开箭头 20dp；加载指示 18dp
- 顶栏规格：`GlassMediumFlexibleTopAppBar`（包 M3 `MediumFlexibleTopAppBar`，未覆写高度，即 M3 默认展开 112dp / 收起 64dp，随滚动折叠），标题过长自动省略，动作按钮顺序即配置顺序
- 底部弹层：`AppModalBottomSheet` 最高 80% 屏高，内容左右 16dp、底部 16–24dp，拖拽把手默认
- 封面：比例固定 5:7；默认封面宽 书架网格 84dp、搜索结果 72dp、书签聚合 52dp
- 选中/激活态：卡片背景换 `secondaryContainer`（对比度靠背景而非边框）；当前阅读章节文字用 primary；开关类菜单项用 `isSelected` 打勾而非 switch
