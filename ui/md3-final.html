尺寸对照

紫色 = 本设计取值　红色 = MD3 标准值。宽度按 dp 等比，可直接看出差多少。
应用栏 MD3 56dp = 8.7mm
应用栏 本设计 36dp = 5.6mm
搜索框 MD3 48dp = 7.5mm
搜索框 本设计 34dp = 5.3mm
列表项 MD3 56dp = 8.7mm
列表项 本设计 42dp = 6.6mm
按钮 MD3 40dp = 6.2mm
按钮 本设计 34dp = 5.3mm
为什么按紧凑版取值
屏高只有 248dp。MD3 标准的「应用栏 56 + 搜索框 48 + 按钮 40」= 144dp，占 58%，只剩 104dp 放内容 —— 一屏看不到 3 条记录。 按本设计「36 + 34 + 34」= 104dp，占 42%，剩 144dp 放内容，一屏 3~4 条。
取舍清单
项取值理由
字号下限10sp再小在 326ppi 上要凑近看，走路时危险
正文12sp / 行高 1.8手表阅读距离近，行距不足易串行
点击目标≥32dp（5.0mm）指尖在表盘上的有效精度下限
整宽按钮不用 FAB方屏右下角放 FAB 会挡住列表末项
深色主题默认AMOLED 深色省电，手表续航敏感
圆角26dp对齐真机四边等宽方屏的物理圆角
列表项42dp两行文本 + 上下各 ~5dp 内边距，刚好不挤
还没确认的一件事
density 2.0 是按 320dpi 推算的。若真机是别的档（如 213dpi → 284 × 373dp）， 本设计只会显得偏小，不会坏；反之若按 MD3 标准画而真机是 320dpi，就会被裁掉。
所以布局一律用 dp 写、尺寸取偏紧的一档，是两种情况下都安全的选择。
